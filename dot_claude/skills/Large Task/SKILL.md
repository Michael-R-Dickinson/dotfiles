name: Large Task
description: For how to work through large tasks, or tasks where a lot of planning went into it
---
With large tasks your context is highly important as you need to manage the scope and progress of the task. In this case, delegate to sub-agents for most things rather than doing them yourself - unless describing the task is equally easy to implementing (for example when we've already planned something very specific and you have written the code in the plan)
- This includes things like testing, running builds, debugging small errors - these should all be done by sub-agents
