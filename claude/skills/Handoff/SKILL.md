We are now going to shift gears to managing your context window and condensing all key information. Create a handoff markdown document in the most appropriate directory (ideally progress/), if one doesn't exist, create one. This should contain the information for another agent to pick up where you left off. 
- Be brief but aim to condense the key learnings and questions answered.
- Also include at the top, a specific description of the task. Make sure this part is exact - so the next agent continues towards the correct objective.
- Also briefly lay out what you've tried, how you tested, and the result. Don't include too much interpretation in there - keep it simple.
